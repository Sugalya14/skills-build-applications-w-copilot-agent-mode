# OctoFit Tracker — Backend

This folder contains backend scaffolding for the OctoFit Tracker Django app.

Setup (development):

```bash
python3 -m venv octofit-tracker/backend/venv
source octofit-tracker/backend/venv/bin/activate
pip install -r octofit-tracker/backend/requirements.txt
```

This folder includes a minimal Django app package `octofit_tracker` with models, serializers, and viewsets to start building the API.
